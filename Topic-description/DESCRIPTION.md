# TOPIC: CINEMA

A cinema management system could be used by management staff, saler and customers:

* Management staff: view the types of statistics: movies, customers and revenue. Schedule showtimes, manage movie and theater information (add, edit, delete).  
* Saler: selling tickets at the counter to customers, issuing membership cards to customers  
* Customer: register for membership, search, buy tickets online, buy tickets at the counter

13. # **Subject No. 13**

***Considering two  modules***

* ***Management staff adds movie information***: selects the movie information management menu → selects the function to add movie information → enters movie information and clicks add → the system saves to the database.  
* ***Customer purchases online ticket***: selects the ticket purchase menu → selects a movie from the list → selects a viewing time → selects a seat → Enters the loyalty card code (if any) and confirms ticket purchase → pays → prints system tickets and invoices.
